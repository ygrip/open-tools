# Open Tools vector brand assets

These are original SVG source illustrations authored directly for Open Tools, not Fal-generated raster images or downloaded stock assets. They contain no JavaScript, embedded raster images, external fonts, external resources, or SVG filters.

- `logo.svg` — 96 × 96 smiling orange clay toolbox mark.
- `favicon.svg` — simplified 48 × 48 mark for small browser-tab rendering.
- `workbench.svg` — 640 × 520 lightweight fallback/secondary scene, with the same toolbox, mint data tiles, a lavender code card, and magnifier.

Shading uses linear gradients, layered solid shapes, highlights, and translucent elliptical shadows. Transparent backgrounds let the assets sit on light or dark surfaces without separate downloads. Keep the intrinsic aspect ratio. For decorative use, set the embedding image's `alt=""`; otherwise provide an accessible description appropriate to the surrounding content.
