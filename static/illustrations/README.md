# Clay workbench illustration

The smiling toolbox illustration was generated for Open Tools with Fal.ai's `fal-ai/flux/schnell` model, seed `42917`, one 1024 × 1024 image (four inference steps). It is a decorative brand illustration, not a representation of an actual tool feature.

Art direction: soft matte plasticine, orange toolbox mascot with blush cheeks, a lavender code tile, mint data stack, yellow magnifying glass, little clay stars, warm cream studio background and gentle shadows. No existing artist or third-party character was referenced.

For the hero, only optimized WebP derivatives are shipped: 448 × 448 (7.2 kB) and 768 × 768 (14.8 kB), generated with `cwebp` at quality 80/82. The 1 MB source PNG is intentionally not shipped. The responsive hero reserves image dimensions, loads eagerly, and gives the image high fetch priority. No request to Fal is made by the website, and no API credential is stored in this repository.

The 404 search scene and 500 repair scene were generated with the same Fal model, four steps, and seeds `42918` / `42919`. They use original toolbox character art direction rather than referencing a third-party character. The 768px PNG sources are not shipped; WebP derivatives are 384px/640px (404: 8.1/15.5 kB; 500: 7.2/13.5 kB). Both reserve their dimensions and load only on error routes.

The vector logo and favicon in `../brand/` are original SVG artwork, not generated by Fal. The SVG workbench is a lightweight alternate illustration. The pre-Svelte error template includes its own original inline SVG so it remains illustrated even when asset requests fail.
