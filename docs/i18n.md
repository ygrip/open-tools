# Internationalization (Paraglide JS)

Open Tools supports English (`en`, unprefixed) and Bahasa Indonesia (`id`, prefixed).

- `/` and `/json-tools/` remain the original English static URLs.
- `/id/`, `/id/json-tools/`, `/id/privacy/`, `/id/terms/` and `/id/policy/` are separately prerendered Indonesian routes.
- Localized links reload the document to keep the static document language and compiled messages in sync.
- Translations live in `messages/en.json` and `messages/id.json`. Edit both when adding UI copy.
- `npm run build` compiles Paraglide messages before SvelteKit prerenders. Generated output is ignored by git.
- Keep asset and verified JSON bundle requests unprefixed: `/bundles/...`.

The host shell and legal pages are localized. Independent tools are versioned and sandboxed in opaque-origin iframes, so translating their internal UI requires an independent tool release and a versioned extension to the tool contract. Do not add cross-origin messaging or iframe permissions just for translation.

## Verification

```sh
npm ci
npm run build
npm run check
npm run test:e2e
```

Confirm each localized URL serves a complete prerendered page with the appropriate `<html lang>`, localized navigation, working tool iframe, and language links. The default URLs must keep working without redirects.
