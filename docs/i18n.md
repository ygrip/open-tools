# Internationalization (Paraglide JS)

trick-it supports English (`en`, unprefixed) and Bahasa Indonesia (`id`, prefixed).

- `/` and `/json-tools/` remain the original English static URLs.
- `/id/`, `/id/json-tools/`, `/id/privacy/`, `/id/terms/` and `/id/policy/` are separately prerendered Indonesian routes.
- Language links retain route, query and fragment, then reload the document to synchronize static HTML and compiled messages. Save input before switching languages. Navigation within a locale remains client-side SPA routing.
- Translations live in `messages/en.json` and `messages/id.json`. Edit both when adding UI copy.
- `npm run build` compiles Paraglide messages before SvelteKit prerenders. Generated output is ignored by git.
- Keep asset and verified JSON bundle requests unprefixed: `/bundles/...`.

The shell, legal/error pages, SEO/social cards, runtime permission UI and local JSON Tools mirror support English/Indonesian. Tools remain independent, versioned, opaque-origin iframes. Declare actual interface `locales` (default English), provide metadata `translations`, and respond to `trick-it:localechange` without clearing editors. The host initializes document language before tool scripts run and uses the first supported language if the selected platform locale is unavailable. The SDK exposes that effective language as `window.trickIt.locale`. No `allow-same-origin` permission is added. See [v3 metadata](tool-contract-v3.md) and [the runtime guide](tool-runtime.md).

## Verification

```sh
npm ci
npm run check
npm run build
npm run test:e2e
```

Confirm each localized URL serves a complete prerendered page with the appropriate `<html lang>`, localized navigation, working tool iframe, and language links. The default URLs must keep working without redirects.
