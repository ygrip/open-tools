JSON Tools

Format JSON, select values with JSONPath, or convert between JSON and XML.

Property, index, slice, wildcard and recursive selectors are supported. Script and filter evaluation is disabled.

Processing stays in this frame. Input is limited to 1,000,000 characters. JSON to XML adds a <root> element; XML text and attribute values remain strings. Numbers use JavaScript floating-point precision; unsafe integers are rejected. Encode exact decimals and large integers as strings.
